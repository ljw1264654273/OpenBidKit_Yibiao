# 紧凑侧边菜单设计

## 背景

当前客户端侧边栏默认展开，宽度较大，菜单项同时展示标题和较长描述，导致主内容区域被压缩。用户提供的参考图片展示了一种更轻量的导航方式：菜单以图标和名称为主，选中项使用浅色背景，整体占用空间较小。

本需求只调整客户端 Renderer 的侧边菜单表现和轻量 UI 状态，不修改菜单配置、页面路由、业务功能或 Main/preload/IPC。

## 目标

- 侧边菜单整体更紧凑，减少对主内容区域的占用。
- 菜单项主要显示图标和菜单名称，隐藏侧栏中的长描述。
- 选中项使用简洁的浅紫色背景和主题色文字。
- 保留当前已有的展开/收缩按钮及点击切换行为。
- 首次使用时菜单默认收缩。
- 用户切换后记住状态，下次启动时恢复上次状态。
- 收缩状态下继续通过现有 Tooltip 识别菜单项。

## 非目标

- 不改变菜单项顺序、层级、名称、路由或业务行为。
- 不增加鼠标悬停临时展开。
- 不新增数据库、IPC、Main 服务或 preload API。
- 不改变二级菜单页面及其他页面中的菜单描述。
- 不重做应用整体主题或主内容区域布局。

## 设计方案

### 侧边栏状态

`Sidebar` 继续使用现有 `collapsed` React state 和现有展开/收缩按钮。状态初始化时读取一个专用 `localStorage` 键：

- 键名：`yibiao.sidebar.collapsed`
- 存储值：`"true"` 或 `"false"`
- 没有记录时：按收缩状态初始化。

用户点击现有按钮时，沿用当前切换逻辑，并在状态变更后同步写入 `localStorage`。这样首次使用默认收缩，后续启动恢复用户上次选择。该数据属于轻量 UI 偏好，符合项目对 Renderer `localStorage` 的使用边界。

### 展开状态

- 侧栏宽度从当前约 `286px` 收窄到紧凑的固定宽度，建议约 `220px`。
- 保留品牌区域，但降低其垂直占用。
- 菜单项只显示图标和一级菜单名称，不再在侧栏显示 `description`。
- 菜单项高度、内边距和菜单间距降低，保证较多菜单项时仍能在侧栏内部滚动。
- 图标不再使用明显的渐变底框，使用简洁线性图标和主题色状态。
- 激活项使用浅紫色背景、主题色文字和轻量边框，不使用大面积蓝紫渐变或强阴影。

### 收缩状态

- 保留当前收缩宽度机制，调整为更紧凑的图标栏宽度，建议约 `72px`。
- 隐藏品牌文字、菜单文字和设置文字，保留图标。
- 继续使用现有 Radix Tooltip 显示菜单名称、文档和设置。
- 激活项仍使用浅紫色背景，保证当前页面在图标模式下可识别。
- 现有展开/收缩按钮保留在侧栏边缘，按钮位置和旋转方向保持原有语义。

### 底部入口

文档和设置继续位于侧栏底部，遵循与主菜单相同的紧凑尺寸和激活样式。文档仍打开现有外部使用文档地址，设置仍切换到现有设置页面。

## 代码边界

预计修改：

- `client/src/components/Sidebar.tsx`
  - 增加侧栏状态的 `localStorage` 初始化和持久化。
  - 隐藏侧栏菜单中的描述文本，保留现有 Tooltip、按钮和点击逻辑。
- `client/src/styles/layout-app-shell.css`
  - 调整侧栏展开/收缩尺寸、菜单间距、图标和选中样式。

预计不修改：

- `client/src/app/menuConfig.ts`
- `client/src/shared/types/navigation.ts`
- `client/src/app/AppRouter.tsx`
- Main、preload、IPC 和 Analytics 代码。

## 数据流

1. `Sidebar` 挂载。
2. 从 `localStorage` 读取 `yibiao.sidebar.collapsed`。
3. 有效值为 `"true"` 时以收缩状态挂载，有效值为 `"false"` 时以展开状态挂载；无值时使用收缩状态。
4. 用户点击现有展开/收缩按钮。
5. React 更新 `collapsed`。
6. 同步写入新的布尔字符串。
7. 组件继续使用现有 CSS class 控制展开和收缩呈现。

菜单项点击仍只调用现有的 `onSectionChange`，不会改变导航数据流。

## 异常与兼容

- `localStorage` 无记录、值不是 `"true"`/`"false"` 或读取失败时，回退到默认收缩状态。
- 写入偏好失败不影响菜单切换，React 内存状态仍正常更新。
- 现有菜单 Tooltip、页面跳转和底部入口行为保持不变。
- `prefers-reduced-motion` 继续由现有全局样式控制。

## 验证

### 自动验证

- 在 `client/` 执行 `npm run build`，确认 TypeScript 检查和 Vite 构建通过。

### 手动验证

- 清除 `localStorage` 后启动，确认侧栏默认收缩。
- 点击现有按钮展开，关闭并重新打开客户端，确认仍为展开。
- 再次收缩并重新打开客户端，确认仍为收缩。
- 在展开状态检查菜单只显示图标和名称，长菜单描述不再撑高菜单项。
- 在收缩状态检查所有菜单、文档和设置 Tooltip 可用。
- 检查所有现有一级菜单、二级入口和设置入口仍可点击。
- 检查菜单较长时滚动区域正常，未影响主内容区域和 `FloatingToolbar`。
