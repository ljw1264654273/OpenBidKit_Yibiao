# 标书模板强制内容规范设计

## 目标

在标书模板设置中明确展示四条不可关闭的内容规范，并让技术方案目录、正文生成、正文调整和配图生成统一遵守这些规范，避免再次出现标题标点、工期越界和并列分项缺少编号的问题。

## 已确认的强制规则

1. **正式章节标题不得带结尾标点。** 目录标题及各级正式章节标题末尾不得出现句号、冒号、逗号、分号等标点符号。
2. **进度计划必须在招标要求期限内完成。** 以招标文件规定的工期、服务期限和交付节点为硬性边界；允许压缩周期、交叉作业和并行推进，不评估实际执行难度，但全部工作、验收和成果交付不得超期。没有绝对日期时使用合同签订或项目启动后的相对时间，不得安排开标、中标或合同生效前的实施工作。
3. **正文加粗引导标题后必须使用中文冒号。** 加粗引导标题与正文位于同一段时，标题末尾使用中文冒号，冒号包含在加粗范围内，之后直接衔接正文，不得使用句号。
4. **并列分项标题必须使用数字序号。** 同一章节下存在两个及以上并列论述分项时，按出现顺序使用连续阿拉伯数字序号，格式为 `1. 标题`、`2. 标题`、`3. 标题`。

## 产品形态

四条规则对所有标书模板强制生效，不提供开关或自定义值。因此不把它们设计成可变的模板 JSON 字段，也不增加数据库 migration、IPC 参数或模板兼容分支。

在新建和编辑模板页面增加“内容规范”页签，以只读、锁定状态展示四条规则。页面负责让用户明确知道模板会执行哪些约束，规则的实际执行由 Main 侧生成和保存链路负责。旧模板打开后自动看到并执行同一组规则，不需要迁移已有 `export_templates.config_json`。

## 执行边界

### 正式章节标题

在 Main 侧建立纯函数，清理正式目录标题末尾的句号、冒号、逗号、分号、顿号和问叹号。生成目录和用户编辑目录最终都通过 `technicalPlanStore.saveOutline()` 持久化，因此在 Store 保存入口统一规范化，避免 Renderer、生成任务和导出服务各复制一套逻辑。

标题规范化只修改 `title`，不修改编号 `id`、描述、正文或评分覆盖关系。括号、书名号等作为标题组成部分时不处理，避免破坏完整名称。

### 加粗引导标题和并列分项

沿用 `contentGenerationTask.cjs` 现有保存前 Markdown 规范化入口：

- 行内加粗引导标题后有正文时，末尾句号改为中文冒号，并清理加粗结束标记外的重复分隔标点；无论加粗标记前是否已有数字序号都必须执行。
- 独立成行的加粗标题仍按正式标题处理，不保留句末标点。
- 同一叶子小节内出现两个及以上独立并列加粗分项标题时，为这些标题补齐连续的 `1.`、`2.`、`3.` 序号；已经连续且正确的编号保持不变。
- 并列标题的标准 Markdown 形式固定为独立行 `1. **标题**`；标题与正文同一行时固定为 `1. **标题：** 正文`。缺号、跳号、重号或乱序时按正文出现顺序统一重排。
- fenced code、Markdown 表格、图片标记和普通正文中的加粗术语不参与改写。

同时修改正文首次生成、普通原方案优化扩写、原方案优化扩写 Agent fallback 和字数调整提示，删除各处“加粗引导语禁止编号”的冲突约束，明确并列分项必须编号。保存前规范化作为确定性兜底，保证模型偶发不遵守时仍能落成统一格式。

### 进度计划

进度约束需要理解招标事实，不能靠字符串替换完成。将同一条强制工期指令注入以下路径：

- 小节正文编排：直接使用 Step02 已提取的工期、服务期限和交付节点判断时间边界。
- 正文首次生成与原方案优化扩写：不得编造早于开标、晚于交付期限的绝对日期；未给定绝对日期时改用相对时间。
- 字数调整、原方案覆盖修复以及普通/Agent 一致性修复：不得在扩写或修复时引入越界日期，也不得为了“更现实”主动延长工期；这些路径都必须直接接收 Step02 工期事实。
- Mermaid、HTML 和 AI 配图：进度图、甘特图及时间轴只能复用最终正文中的时间范围和节点，不得自行推算或新增日期；语法修复和布局修复提示同样执行，不允许重试时绕过。

计划可以紧凑，允许并行、交叉和压缩安排；审查重点仅是不得超出招标期限，不判断现实资源是否足以完成。

## 错误处理与兼容

- 四条规则不依赖模板保存状态，即使用户尚未创建导出模板，正文生成仍执行。
- 旧模板无需数据迁移；只读内容规范页签由应用版本提供。
- 已有历史正文不批量改写；新生成、重新生成或字数调整后写回的内容执行新规则。
- 用户手工编辑目录并保存时清理标题末尾标点；正文手工编辑保持用户原文，不在保存时额外重排并列编号。
- 规则处理失败不得静默破坏正文；纯函数保持幂等，并通过定向测试覆盖受保护 Markdown 区域。

## 验收标准

- 新建和编辑任意模板时均能看到四条锁定的内容规范，且没有关闭入口。
- 目录保存后，所有正式标题末尾不存在规定的句末标点。
- 新生成或调整写回的正文中，行内加粗引导标题使用中文冒号；同一小节的多个并列分项标题使用连续数字序号。
- 进度类正文和生成的甘特图、时间轴不早于项目合法起点、不晚于招标要求交付期限；未提供绝对日期时使用相对时间。
- 现有模板、Word 排版、正文生成、原方案扩写和配图流程保持兼容。
