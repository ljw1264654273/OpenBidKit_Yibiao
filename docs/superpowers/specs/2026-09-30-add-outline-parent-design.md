# 标书目录添加父目录设计

## 背景

标书生成第三步已经支持添加一级目录、添加子目录和 AI 添加子目录，但无法在已有目录项外层补建父目录。用户需要在不重做现有目录内容的前提下，把当前目录项及其完整子树整体下移一级。

## 目标

- 在目录项详情操作区增加“添加父目录”。
- 新父目录占据当前节点原有位置，当前节点及其全部后代成为新父目录的子树。
- 新父目录创建后自动选中、展开并进入标题与描述编辑状态。
- 目录最多保持七级；包裹后超过七级时禁止操作并给出中文提示。
- 原节点及其后代的正文、知识库关联、生成状态和评分覆盖关系按新编号迁移并保留。
- 变更同时适用于共用 `OutlineEditPage` 的技术方案和已有方案扩写入口。

## 非目标

- 不增加 AI 生成父目录。
- 不支持一次包裹多个同级节点。
- 不修改目录拖拽排序规则。
- 不扩展可行性研究报告目录页面。

## 交互设计

“添加父目录”与“编辑”“添加子目录”“AI 添加子目录”“删除”位于同一详情操作区。

点击后执行以下行为：

1. 在当前节点原位置创建标题为“新目录项”、描述为“请编辑描述”的父节点。
2. 把当前节点及其完整子树作为该父节点唯一的直接子节点。
3. 重新编号整棵目录树。
4. 通过 `idMap[临时父节点 ID]` 取得重编号后的最终 ID，自动展开、选中新父节点并进入编辑状态。
5. 保存成功后显示“父目录已添加”的成功提示；失败时显示可操作的失败信息。

当当前子树的最深叶子已经位于第七级时，按钮禁用。若通过状态变化触发到处理函数，函数仍显示“目录最多支持七级，不能继续添加父目录”的普通提示。目录排序、目录生成或正文生成处于锁定状态时，沿用现有目录变更锁定规则。

## 树变换与编号

新增一个纯树变换辅助函数，根据节点 ID 在根数组或任意父节点的 `children` 中原位替换：

```text
变更前：A
        ├─ B
        └─ C

变更后：P（新父节点）
        └─ A
           ├─ B
           └─ C
```

新父节点使用不会与现有 ID 冲突的临时 ID。当前节点继续保留变换前 ID，随后由现有 `renumberOutlineItemsWithIdMap()` 一次性生成最终 ID 和映射：临时父节点映射到当前节点原编号，当前节点及后代映射到下移一级后的编号。这样可以复用现有全树编号规则，并让 Main Store 准确迁移持久化数据。

深度判断不能只检查当前节点自身层级，而要计算当前子树最大深度。只有 `当前子树最大深度 < 7` 时才允许整体下移。

## 持久化协议

在 Renderer 和 Main 的保存原因联合类型/白名单中新增 `add-parent`，不复用 `add-child` 或 `sort`。

保存请求包含：

- `reason: 'add-parent'`
- 重新编号生成的完整 `idMap`
- 空的 `affectedNodeIds`

`add-parent` 是非排序结构变更，因此使正在使用旧目录结构的整体正文任务和 runtime 失效。由于原节点语义和正文没有变化，不把其标记为受影响节点；Store 通过 `idMap` 将原有正文、节点知识库关联、节点级正文生成状态、全文图片计划及其图片引用和评分覆盖节点 ID 迁移到新编号，避免正文保留图片块但资源被清理后出现断图。

评分覆盖维护把 `add-parent` 与 `add-root`、`add-child` 同类处理：识别映射后仍不存在于旧目录的节点，并为新父节点追加 `user-supplement` / `user-added` 记录。原节点的评分关系按 `idMap` 保留。

## 错误与边界

- 无目录数据、排序中或目录被任务锁定时不执行。
- 当前节点不存在时不保存，并显示添加失败信息。
- 当前子树下移后超过七级时不保存。
- 根节点和非根节点使用相同的原位包裹算法。
- 新父节点成为分支节点，不设置叶子专用的 `content_mode`；原节点变成唯一子节点后仍按现有内容模式归一化规则处理。

## 验证

- 纯函数测试覆盖根节点包裹、嵌套节点包裹、兄弟顺序不变、子树整体保留和七级限制。
- 页面结构测试覆盖“添加父目录”入口、`add-parent` 保存原因、成功提示和自动编辑状态。
- Store 定向测试覆盖 `add-parent` 后正文、关联状态和全文图片计划通过 `idMap` 保留，新父节点加入评分覆盖映射，以及整体正文任务/runtime 按非排序变更失效。
- 运行现有技术方案相关定向测试和 `npm run build`。
- 手动验证技术方案与已有方案扩写两个入口的按钮状态、节点选择、展开、编辑和七级限制。
