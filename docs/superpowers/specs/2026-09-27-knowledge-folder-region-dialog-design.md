# 知识库新建文件夹弹窗与所属省市

## 范围

本地知识库的六个分类（文档知识库、国标文档、省标文档、市标文档、行业标文档、企业文档）共用 `KnowledgeBasePage` 的新建文件夹流程。本次将顶部内联表单替换为项目现有风格的 `AppDialog`，并为文件夹增加可选的所属省份和城市。远程知识库、图片知识库、文件夹重命名、地域筛选和文档内容不在本次范围。

## 交互

- “新建文件夹”和空状态入口打开同一个弹窗。弹窗包含必填的文件夹名称、可选省份和可选城市，以及取消、创建操作。
- 省份和城市使用本地的省市级联选项，离线可用。没有省份时城市不可选；选择或更换省份时清空先前城市；允许只选省份，也允许二者均不选。
- 创建中防止重复提交及关闭；失败时保留输入并在弹窗中显示现有 Toast 错误；成功时关闭并清空表单、选中新文件夹，沿用现有成功提示。
- 文件夹列表在名称旁或下方展示已保存的省市；没有地域信息时不显示占位。现有文件夹保持原样，不做批量补全。

## 数据流

`KnowledgeFolder` 增加可空的省、市字段。创建调用从 Renderer 经 preload、IPC、service 传至 `knowledgeBaseStore`，写入 `knowledge_folders`；列表读取和创建返回值都包含这两个字段。数据库增加一次向前迁移，旧行默认为空，同步根目录目标 schema。保持现有分类、排序、移动文档和删除语义不变。省市选项在 Renderer 本地维护，不依赖在线 API 或运行时网络。

## 验证

覆盖空地域、省份独选、省市同选及切换省份清空城市；确认六个分类共享弹窗，创建后显示地域，重新进入页面仍能显示，旧文件夹正常读取。对 Store 增加定向测试，执行相关 `.cjs` 语法检查、Electron native smoke、`npm run build`，并在开发窗口检查弹窗尺寸、键盘操作和列表布局。
