# 新增章节默认定向改写与推荐提纲

用户已确认：第四步新增章节及新增父目录下属正文节点，在第五步默认定向改写。AI 根据章节路径、编制说明、招标基线、关联已确认差异生成写作提纲，填入可编辑的“定向改写要求”。校核后点击“按此方式迁移本章”才生成正文。

Main 的既有正文任务增加仅生成提纲的运行模式；第五步进入时自动建立缺失方案并启动此模式，不生成其他章节正文。普通批量迁移可生成缺失提纲，但跳过尚未人工应用要求的新增章节。推荐提纲和人工要求分开保存到既有 SQLite JSON 状态，不新增表。重建时保留同输入提纲；已应用人工要求始终优先。恢复默认清除人工要求并回填推荐提纲。

提纲请求复用 aiService 和任务作用域，以 checkpoint 持久保存，页面卸载不取消。失败逐章记录并允许通过“建立/更新迁移”重试，用户也可直接填写要求。页面提示生成中、推荐提纲待校核和失败恢复操作。

验证包括纯 Main 任务测试、真实 SQLite 保存/重开测试、TypeScript 构建、Electron native smoke，以及浏览器交互和 Electron 开发启动检查。
