# 全局事实模式精简设计

## 目标

将全局事实设定从三个模式精简为两个模式：删除“胡咧咧模式”，将原“别招欠模式”显示为“标准模式”，将原“放着我来模式”显示为“严谨模式”，并让“标准模式”成为所有新建、重置、缺省和旧配置回退场景的默认模式。

## 模式语义

- `omit`：显示名称为“标准模式”。保留现有“不编造具体值、使用符合招标要求的笼统口径”的行为。
- `placeholder`：显示名称为“严谨模式”。保留现有“任何不确定项使用【待填写】占位”的行为。
- `fabricate`：不再作为可选或可执行模式。历史数据、缓存或调用参数中出现该值时，统一归一化为 `omit`。

## 修改范围

### Renderer

- `GlobalFactsMode` 类型只保留 `omit | placeholder`。
- 配置对话框只显示“标准模式”和“严谨模式”。
- 两个模式的说明移除对“胡咧咧模式”的引用，直接描述各自选题范围和缺失事实处理方式。
- 初始状态、缓存回退和页面属性回退全部使用 `omit`。

### Electron Main

- 全局事实生成、正文生成和 Store 的模式归一化均只接受 `omit`、`placeholder`；其他值（包括历史 `fabricate`）回退为 `omit`。
- Prompt 中的模式标题改为“标准模式”和“严谨模式”。
- 删除或封闭原先允许模型补造具体事实的默认分支，使任何旧输入都无法继续触发杜撰行为。
- 工作区重置后的模式改为 `omit`。

### SQLite 与兼容性

- 新数据库及新列的 `global_facts_mode` 默认值改为 `omit`。
- 根目录 `sql/workspace_schema.sql` 同步为 `omit`。
- 增加数据库迁移，将已有 `technical_plan_meta.global_facts_mode = 'fabricate'` 的记录改为 `omit`。
- 即使迁移未运行或外部传入旧值，Renderer、Store 和任务服务的归一化仍会将其映射到 `omit`。

## 验证

- 增加自动化测试，覆盖默认模式、历史 `fabricate` 回退、两个保留模式的 Prompt 标题和行为。
- 对修改的 Electron `.cjs` 文件运行 `node --check`。
- 在 `client/` 运行定向 `node --test` 测试与 `npm run build`。
- 检查最终 diff，确认未修改当前工作区已有的标书查重相关文件。

## 非目标

- 不调整配置对话框的视觉样式或布局。
- 不改变“标准模式”和“严谨模式”原有的业务处理规则。
- 不修改与全局事实模式无关的技术方案流程、埋点或在线服务协议。
