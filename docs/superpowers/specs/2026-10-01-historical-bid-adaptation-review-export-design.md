# 历史标书适配环节六：审核导出设计

## 目标与范围

为“历史标书适配”增加最终审核与 Word 导出环节。只审核当前项目适配后的技术方案，依据已确认招标基线、差异台账、适配目录、正文和正文来源元数据执行确定性检查；不生成或改写正文，不处理商务册、报价册、三册制文件，也不提供扩写、压缩或删减字数控制。

## 工作流与页面

环节六只在环节五正文已全部确认后开放。页面提供“运行终审”和“重新终审”，结果按 P0 阻断、P1 重要、P2 提示分级，并支持按级别筛选、定位到章节、查看检查证据、将问题标记为已整改或经人工确认。重新终审只保留同一规则、同一章节和同一证据指纹对应的问题处理状态；正文、差异或目录改变时清空终审结果和验收状态。

终审结果区展示各级数量、结论与更新时间。P0 未关闭时不可验收、不可导出；P1/P2 仅提示，由用户审阅。所有章节仍须正文非空且已确认。终审通过后，用户执行“确认终审”作为人工验收。确认后出现“导出 Word”，复用现有 `WordExportDialog`、导出模板和 `window.yibiao.export.onWordExportProgress()` 流程，导出当前 `outlineData.outline`。

窄屏下问题列表、证据/处置与验收区纵向排列，内容在页面内滚动。

## 自动检查规则

- P0：叶子章节缺失正文迁移记录、正文为空、正文未确认；旧地点/行政层级/日期/工作量等正文迁移元数据中的阻断残留仍出现；存在 `【待核实】`、`【待补充】` 占位内容；删除类差异的历史内容仍在对应适配正文中出现。
- P1：已确认差异未关联到任何正文迁移章节；存在招投标禁用的模糊表达（如“可能、大概、也许、应该、左右、尽量”）；被标记为忽略的差异提示用户复核。
- P2：规则未覆盖的人工判断提醒，例如存在“其他人工判断”类差异，终审规则不对其语义正确性作自动结论。

问题 ID 基于规则、章节与证据指纹稳定生成。人工处置只针对当前证据指纹；内容改变会使审核整体失效，避免旧的人工关闭状态覆盖新问题。自动规则只提供可定位检查，不宣称能证明自然语言语义完全符合招标要求。

## 数据与接口

在技术方案项目元数据增加 `historical_adaptation_review_findings_json` 与 `historical_adaptation_review_confirmed_at`，作为终审问题及人工验收的权威状态。终审由 Main 侧 Store 读取权威 SQLite 数据、运行纯规则、一次事务持久化结果；问题处置及确认同样通过 Store/IPC 保存。此扫描为本地确定性规则，不引入单独后台任务或 AI 调用。

正文、差异及适配目录的任何更新均使终审问题与确认时间失效。导出前由 Store 检查终审确认、P0 清零及环节五确认；页面禁用状态仅作体验提示，权威门禁在 Main 侧执行。
