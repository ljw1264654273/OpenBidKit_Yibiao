# STEP 03 目录项知识库选择优化设计

## 目标

优化技术方案 STEP 03「目录生成」右侧目录详情中的知识库操作，解决一级知识库较多时无法明确归属的问题。

用户操作必须遵循固定层级：

`一级知识库 → 文件目录 → 知识库文档`

其中一级知识库是现有的固定分类，例如「国标知识库」「省标知识库」；文件目录是分类下的已有文件夹；知识库文档属于具体文件夹。

本次只优化入口和选择流程，不修改数据库结构，不改变正文生成时“当前目录及父目录继承知识库”的业务规则。

## 交互设计

### 新增知识库内容

入口仍为「新增知识库」，打开一个统一弹窗，按上下顺序展示三段内容：

1. **选择一级知识库**
   - 展示现有 `KNOWLEDGE_BASE_CATALOG` 分类。
   - 初始不默认选中，避免用户未确认归属就创建或上传。
   - 切换一级知识库时清空目录和文档相关选择。

2. **选择目录**
   - 只展示当前一级知识库下的已有目录。
   - 支持选择已有目录。
   - 提供「新建目录」入口；新建时只填写目录名称，不增加额外弹窗。
   - 新建目录需要携带当前选中的 `knowledgeBaseId` 创建，不能回退到默认一级知识库。
   - 未完成一级知识库选择时，目录区不可操作。

3. **上传文档**
   - 目录确定后，主操作按钮变为「选择并上传文档」。
   - 复用现有 `knowledgeBase.uploadDocuments(folderId)` 文件选择能力，支持一次选择多个文档。
   - 已有目录和新建目录都走同一套上传流程。
   - 上传完成后，将该目录 ID 关联到当前目录节点；目录关联意味着该目录内后续处理成功的文档都可用于正文生成。

弹窗底部显示简短摘要：

`国标知识库 / 施工规范 / 待上传`

创建目录后用户取消文件选择时，保留空目录和目录节点关联，允许后续在知识库模块继续上传。

### 关联文档

入口仍为「关联文档」，打开同样风格的统一弹窗：

1. 选择一级知识库。
2. 选择该一级知识库下的一个文件目录。
3. 展示该目录下状态为 `success` 的文档列表。
4. 勾选一个或多个文档。
5. 点击「保存关联」。

一次操作只处理一个一级知识库下的一个文件目录，但可以多选该目录中的文档。需要关联其他目录时，用户重新打开弹窗重复操作。

状态联动：

- 切换一级知识库时清空目录和文档选择。
- 切换目录时清空文档选择并刷新文档列表。
- 未选择目录时不显示跨目录文档，避免把文档误归类到其他目录。
- 没有可用文档时显示清晰空态，并保留切换一级知识库和取消操作能力。

## 目录详情展示

当前目录详情继续展示直接关联和父目录继承的知识库内容，但信息补充为：

`一级知识库 / 文件目录 / 文档`

至少能看出每个文件夹属于哪个一级知识库，避免同名目录造成误判。

保留现有「解除关联」逻辑：

- 解除文件夹关联只解除当前技术方案目录节点与文件夹的关系，不删除知识库目录和文档。
- 解除文档关联只解除当前技术方案目录节点与文档的关系，不删除知识库文档。
- 父目录继承项不提供直接解除按钮，只能回到对应父目录处理。

## 数据与接口

继续复用现有数据和 IPC：

- `knowledge_base_id`：一级知识库分类。
- `knowledge_folder_ids_json`：目录节点直接关联的知识库文件夹 ID。
- `knowledge_document_ids_json`：目录节点直接关联的知识库文档 ID。
- `knowledgeBase.list({ knowledgeBaseId })`：按一级知识库加载目录和文档。
- `knowledgeBase.createFolder(name, knowledgeBaseId)`：在指定一级知识库下创建目录。
- `knowledgeBase.uploadDocuments(folderId)`：向指定目录上传文档。
- `onOutlineNodeKnowledgeSaved(...)`：保存当前目录节点的文件夹/文档关联。

不新增数据库表、字段或 IPC 通道。Renderer 只负责选择状态和交互编排，Main 继续负责知识库持久化、解析和后台处理。

关联变化沿用现有 Store 失效规则：保存目录或文档关联后，清理受影响目录及后代叶子节点的正文生成状态、编排计划和配图计划，保证下次生成使用最新知识库资料。

## 失败和边界

- 一级知识库加载失败：弹窗显示错误提示，不允许继续进入目录选择。
- 新建目录失败：保留弹窗中的一级知识库和目录输入内容，允许重试。
- 新建目录成功但取消上传：保留空目录和目录关联，提示可稍后上传。
- 上传失败：保留目录关联，沿用现有文档解析提示和错误 Toast。
- 选择已有目录后没有可用文档：显示空态，不允许提交空的文档关联。
- 目录或文档已关联：保存时去重，不能生成重复 ID。
- 删除或失效的目录/文档：正文生成时自然忽略不可用项；详情允许解除残留关联。
- 正文生成运行、暂停或目录生成期间：继续禁止新增、上传、关联和解除关联。
- 关闭弹窗未点击保存或上传：只清理临时选择状态，不写入关联关系。

## 实现范围

- `OutlineEditPage.tsx`
  - 增加一级知识库、目录和文档的级联选择状态。
  - 将新增流程改为“选一级知识库 → 选已有/新建目录 → 上传并关联”。
  - 将关联文档流程改为“选一级知识库 → 选目录 → 多选文档 → 保存”。
  - 复用现有知识库分类、列表和上传 API。
- `feature-technical-plan.css`
  - 增加紧凑的三级选择布局、目录选择和摘要样式。
  - 保持当前弹窗、按钮和详情区域视觉风格。
- 相关 Renderer 测试
  - 覆盖一级知识库切换清空下级选择。
  - 覆盖已有目录和新建目录两条新增路径。
  - 覆盖文档按一级知识库和目录过滤。
  - 覆盖取消、空态、重复关联和锁定状态。

无需修改 Main、preload、IPC、SQLite schema 或 Analytics。
