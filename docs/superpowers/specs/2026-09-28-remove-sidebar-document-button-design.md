# 移除侧边栏文档按钮设计

## 目标

从客户端主窗口侧边栏底部移除“文档”按钮，使底部仅保留“设置”入口。

## 范围

- 修改 `client/src/components/Sidebar.tsx`。
- 删除“文档”按钮及折叠状态下对应的 tooltip。
- 删除仅供该按钮使用的 Wiki URL、外链打开函数、渲染函数和书本图标组件。
- 保留“设置”按钮及其布局、状态和交互。
- 保留知识库、模板、文档处理等所有业务页面和路由。

## 行为

- 展开侧边栏时，底部不再显示“文档”。
- 折叠侧边栏时，不再显示该按钮及“使用文档”tooltip。
- 用户仍可正常打开设置页。

## 验证

- 运行 `cd client; npm run build`，确认 TypeScript 检查和 Vite 构建通过。
- 检查 `Sidebar.tsx` 中不存在因移除按钮产生的未使用常量、函数或图标组件。

## 非目标

- 不修改外部 Wiki 内容或部署。
- 不删除任何文档、知识库或模板业务功能。
- 不调整侧边栏其他菜单项、样式或间距。
