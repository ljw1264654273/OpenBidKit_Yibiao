# 历史标书适配：受影响段落语义重写设计

日期：2026-10-09
状态：已确认，按此方案实施

## 背景

历史标书适配在“总则”等章节中会同时识别短名称、带行政层级名称和完整实施主体名称。当前这些证据可能被拆成多个局部 `replace` 编辑，导致范围嵌套，最终触发 `edit ranges overlap`。更重要的是，涉及地区、服务对象、项目名称、地理概况、行政区划或工作量时，机械替换名称不能保证正文仍符合招标文件。

## 目标与原则

- 招标文件及已确认的招标基线是事实标准，不以历史正文长度或“最长原文优先”决定结果。
- 同一完整段落内涉及同一事实变化的重叠证据必须归并为一个 `rewrite-fragment`，禁止继续生成嵌套 `replace`。
- AI 自动重写受影响的完整段落，保留仍适用的通用方法、流程和管理措施，删除旧地区、旧项目、旧服务对象和旧工作量等不适用事实。
- 重写完成后自动进入一致性复核；其他章节不因单个段落失败而停止。
- 精确替换只保留给独立、明确且不需要语义判断的值，例如单独的金额或数量。

## 触发与范围

以下任一条件成立时，差异升级为语义重写：

- 差异动作或说明要求“删除”“重写”“按新地区实际编写”或同义表述；
- 差异范围涉及实施地点、服务对象、项目名称、地理概况、行政区划、人口、工作量等事实集合；
- 同一段落内出现相互包含的证据范围，或多个证据的替换会改变句子结构/上下文。

系统逐段定位证据命中的完整段落，不跨段落扩张；同一差异可以绑定多个段落。同段所有相关差异（包括工作量精确替换）一并归入该段落请求，段外独立值保留精确替换。执行层用 `paragraphRewrite` 标记隔离新语义路径，保留原差异的旧/新事实映射；既有显式锁定片段协议保持原约束。

## 重写输入与约束

重写请求必须同时提供：

- 历史段落原文及其章节路径；
- 招标文件中对应要求、已确认招标基线和相关事实；
- 本次差异的目标动作及证据映射；
- 可保留的通用方法、流程和管理措施。

模型必须返回单一段落正文，不返回多个可能重叠的编辑范围。结果约束如下：

- 新事实只能来自招标文件或已确认基线；
- 当本段招标要求明确提供某类工作量指标时，不得继续保留原段落中未被招标文件支持的旧同类工作量；这项约束不扩展为禁止保留无冲突的人员、设备等技术参数；
- 招标未披露的新地区地理、人口等事实不由模型常识补写，应删除不适用的旧事实；
- 不得残留旧名称、旧地区、旧项目、旧服务对象、旧人口或旧工作量；
- 不得越出输入的完整段落边界；
- 段落中的通用技术措施应尽量保留，事实不适用部分必须删除或重写；
- 返回内容为空、跨段落或包含重叠编辑时，视为本段失败，不应用任何部分结果。

以“总则”示例，五峰村、木渎镇五峰村及旧实施主体的同段证据必须合并处理，正文按横泾街道实际情况重写；横泾街道实施主体、约 3082 宗（其中已调查 2862 宗、未调查 220 宗）等事实来自招标文件，不允许只做名称字符串替换。

## 执行与失败处理

1. 建立迁移方案时，将满足上述条件且历史数据中仍是 `replace` 的差异自动升级为 `rewrite-fragment` 执行规则，保留原始差异协议；保护 `content_origin=manual` 和 `confirmed_at` 的正文，只有用户明确确认覆盖时才执行重写。递增规则/方案版本使旧自动成功结果重新规划。
2. 直接迁移仍尊重用户选择，但一致性检查必须继续报告旧事实残留。
3. 执行前校验片段范围不重叠；模型结果再次校验范围和段落边界，失败则保留历史正文，标记“待人工处理”，记录具体原因，不阻塞其他章节。
4. 正文任务释放组内锁后自动启动现有一致性检查；成功结果及失败保留的底稿均参加复核，检查必须使用 Store 当前正文和招标基线。
5. 切换迁移方式时清除旧的执行错误，避免界面继续展示与当前策略不一致的历史错误。

## 数据与接口边界

- 规则识别、证据归并、段落定位和重写编排留在 Electron Main 的历史适配服务/任务中。
- Renderer 只通过既有 `window.yibiao` IPC 读取状态和触发任务，不直接访问文件或数据库。
- 不修改第四步 `globalFacts` 的语义；历史适配的招标基线和一致性结果继续由现有 SQLite Store 管理。
- 失败诊断只保存必要的范围、节点和错误信息，不保存额外敏感内容，不改变现有 Analytics 能力。

## 验证

- 规则测试：动作说明升级、范围归并、完整段落边界、独立数字精确替换。
- 任务测试：总则示例的单次段落重写、招标基线约束、模型重叠结果拒绝、失败保留原文并继续其他章节。
- Store/状态测试：切换迁移方式清理旧错误、人工确认正文不被覆盖、重写成功后自动进入一致性复核。
- 对涉及的 `.cjs` 执行 `node --check`，运行对应 `node --test`，再执行 `cd client; npm run smoke:electron-native` 和 `npm run build`。
