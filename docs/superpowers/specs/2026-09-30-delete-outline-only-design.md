# 目录生成：仅删除当前目录设计

## 背景

目录生成第三步当前已有“删除”操作，会删除选中目录及其完整子树。用户需要一种保留子目录的删除方式，用于移除不需要的中间目录层级。

## 目标

新增“仅删除当前目录”操作：删除选中节点本身，保留其子节点，并将子节点按原顺序提升到选中节点原来的父级位置。现有“删除”操作继续保持级联删除语义。

## 方案

在 Renderer 目录树纯函数中实现节点提升：

- 叶子节点：从原数组移除，效果与普通删除一致。
- 有子节点的节点：用其 `children` 替换原节点位置；子节点之间的顺序和内部子树不变。
- 一级节点：子节点提升为一级节点。
- 找不到节点时返回未改变结果或 `null`，由页面显示可操作错误。

页面新增独立危险操作按钮“仅删除当前目录”，继续复用现有目录保存编排和 `reason: 'delete'` 协议。保存成功后优先选中被提升的第一个子节点；若没有可选节点则清空选择。Store 不新增 IPC、数据库表或新的保存原因，沿用已有正文、图片、评分映射和编号迁移规则。

## 边界与错误处理

- 仍受目录变更锁、排序状态和正文任务状态限制。
- 删除后目录至少保留一个节点的既有规则继续生效。
- 删除失败时保留当前选择，并通过 Toast 告知失败原因。
- 不新增确认弹窗；按钮文案明确区分级联删除和仅删除当前目录。

## 验证

- 纯树测试覆盖叶子删除、根节点提升、嵌套节点提升、兄弟顺序和子树保留。
- 页面结构测试确认两个删除按钮分别调用级联和提升逻辑。
- 运行相关 Node 测试、`node --check electron/services/technicalPlanStore.cjs`、`npm run smoke:electron-native` 和 `npm run build`。
