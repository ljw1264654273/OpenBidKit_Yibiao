# 知识库分类名称调整设计

## 目标

将五类本地知识库的中文显示名称统一调整为文档名称：

| 旧名称 | 新名称 |
| --- | --- |
| 国标知识库 | 国标文档 |
| 省标知识库 | 省标文档 |
| 市标知识库 | 市标文档 |
| 行业标知识库 | 行业标文档 |
| 企业知识库 | 企业文档 |

## 范围与边界

- 同步客户端知识库目录、页面相关显示文案、Analytics Dashboard 路由中文名、知识库分类测试期望值，以及仓库内设计文档和 README 中对应的历史说明。
- 仅替换上述五类中文名称；通用名称“文档知识库”保持不变。
- 不修改导航 ID、数据库分类 ID、IPC 通道、英文路由、文件目录、埋点事件协议或数据库结构，确保已有工作区和统计数据兼容。

## 实现与验证

1. 对全仓库命中的五类旧中文名称做精确替换，避免修改无关的“数据库”技术术语和 `knowledge-base` 内部标识。
2. 使用 `rg` 复查旧名称不再出现在目标范围，确认新名称覆盖客户端、Dashboard、测试和文档。
3. 在 `client/` 执行 `npm run build`。
4. 定向执行知识库分类测试：`node --test electron/services/knowledgeBaseStore.categories.test.cjs`。
