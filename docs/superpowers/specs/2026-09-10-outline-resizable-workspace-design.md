# 目录生成可调节三分屏设计

## 目标

在保留目录生成默认三分屏布局的前提下，提高多处标书原文的阅读效率，并允许用户按当前任务调整或隐藏任一分屏。

## 已确认交互

- 标书原文不再使用“上一处 / 下一处”切换，所有关联原文按既有顺序连续展示。
- 每个原文块显示“第一处、第二处……”标题，并保留来源类型标签。
- 桌面宽度下，两条竖向分隔线可拖动，实时调整相邻分屏宽度。
- 每个分屏右上角提供隐藏按钮；隐藏后其余分屏均分并铺满工作区。
- 工作区顶部只在存在隐藏分屏时显示恢复入口。
- 至少保留一个分屏，最后一个可见分屏不能隐藏。
- 窄窗口继续使用现有三标签单面板切换，不显示桌面拖拽和隐藏控件。

## 状态边界

- 分屏宽度和隐藏状态仅属于当前页面运行时 UI 状态，不写入 SQLite 或 Main IPC。
- 目录选择、原文关联、排序和详情编辑协议均保持不变。
- 排序期间原文继续使用现有持久快照，连续展示不改变来源计算规则。

## 验证

- 定向 Node 测试覆盖原文连续渲染及工作区控制结构。
- `npm run build` 验证 TypeScript 与 Vite 构建。
- 本地开发环境手动验证拖拽、隐藏、恢复、窄窗口标签切换和多处原文滚动。
